# Referenced runtime components

The release includes only KittenRemoteControl.dll. It does not redistribute any third-party assembly.

- .NET 10 runtime libraries: MIT; provided by KSA. https://github.com/dotnet/runtime
- StarMap.API 0.4.8: provided by StarMap. https://github.com/StarMapLoader/StarMap
- Harmony (installed loader version): MIT; provided by StarMap. https://github.com/pardeike/Harmony
- KSA, Brutal and Planet assemblies: proprietary game components; referenced but never bundled.

Grapevine and Microsoft.Extensions packages used by older versions are no longer dependencies.
The retained LICENSE-Grapevine.txt and historical license notes are not a statement that it is shipped.
